In order to run the project you must have jupyter notebook and other necessary libraries installed in your system.
 Libraries to install before running the project:
	1. sklearn
	2. numpy
	3. pandas
	4. matplotlib
COMMAND TO INSTALL THE LIBRARY: pip install <library name> in the terminal.

HOW TO RUN THE PROJECT?
	Extract the given zip file in a folder. From there open powershell in that folder as depicted
in the video and type the command 'jupyter-notebook' this would start the jupyter notebook server and
you will be able to run the project.
